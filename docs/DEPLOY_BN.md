# Englio অনলাইনে তোলা: ধাপে ধাপে

এই গাইড একদম প্রথমবারের জন্য। একটা ছোট সার্ভারে অ্যাপ, API, HTTPS, রোজকার রিমাইন্ডার আর ব্যাকআপ সব একসাথে চালু হবে। বেশিরভাগ কাজ একটা স্ক্রিপ্ট (`deploy/setup.sh`) নিজেই করে দেয়।

**যা লাগবে:**
- একটা ডোমেইন (এখন ডেমো ডোমেইন হলেই চলবে, পরে আসলটায় সরানো যায়, নিচে ১০ নম্বর দেখো)
- একটা DigitalOcean অ্যাকাউন্ট (international কার্ড দিয়ে)
- কোডটা GitHub-এ push করা থাকতে হবে

---

## ১. সার্ভার বানাও (DigitalOcean Droplet)

1. DigitalOcean-এ **Create → Droplets**।
2. **Region:** Singapore।
3. **Image:** Ubuntu 24.04 (LTS)।
4. **Size:** Basic → Regular → সবচেয়ে ছোটটা (1 GB RAM, মাসে ~$6)।
5. **Authentication:** Password বেছে নাও, শক্ত একটা পাসওয়ার্ড দাও আর লিখে রাখো।
6. চাইলে **Backups** চালু করো (মাসে ~$1.2)। পুরো সার্ভারের সাপ্তাহিক কপি থাকবে, নিশ্চিন্ত থাকা যায়।
7. **Create Droplet**। এক মিনিট পর একটা **IP address** পাবে (যেমন `159.89.10.20`)। এটা লিখে রাখো।

## ২. ডোমেইনকে সার্ভারের দিকে পাঠাও (DNS)

যেখান থেকে ডোমেইন কিনেছ (Namecheap, Cloudflare ইত্যাদি), সেখানে **DNS settings**-এ যাও:

| Type | Host / Name | Value |
| --- | --- | --- |
| `A` | `@` (পুরো ডোমেইন), অথবা সাবডোমেইন যেমন `app` | সার্ভারের IP |

- **Cloudflare ব্যবহার করলে** কমলা মেঘটা বন্ধ (ধূসর, "DNS only") রাখো, নইলে HTTPS সার্টিফিকেট আসবে না।
- DNS ছড়াতে ৫ মিনিট থেকে কয়েক ঘণ্টা লাগতে পারে। কম্পিউটারে PowerShell খুলে `nslookup তোমার-ডোমেইন` লিখলে সার্ভারের IP দেখালে বুঝবে রেডি।

## ৩. সার্ভারে ঢোকো

কম্পিউটারে **PowerShell** খোলো:

```powershell
ssh root@159.89.10.20
```

প্রথমবার `yes` লিখে Enter চাপো, তারপর Droplet-এর পাসওয়ার্ড দাও (টাইপ করার সময় কিছু দেখাবে না, এটাই স্বাভাবিক)। এখন থেকে যা লিখবে সব সার্ভারে চলবে।

## ৪. কোড সার্ভারে আনো

GitHub repo **public** হলে:

```bash
git clone https://github.com/mwhzz/englio-asia.git /opt/englio
```

**Private** হলে: GitHub → Settings → Developer settings → **Fine-grained tokens** → শুধু এই repo-র জন্য *Contents: Read-only* দিয়ে একটা token বানাও, তারপর:

```bash
git clone https://<token>@github.com/mwhzz/englio-asia.git /opt/englio
```

যে branch চালাতে চাও সেটায় যাও (যেমন `cd /opt/englio && git checkout main`)।

## ৫. সেটআপ চালাও

```bash
cd /opt/englio
sudo bash deploy/setup.sh তোমার-ডোমেইন.com তোমার@ইমেইল.com
```

৫ থেকে ১০ মিনিট লাগবে। এটা নিজে নিজে Node, Caddy (HTTPS), ডেটাবেস, API, রিমাইন্ডার, রোজকার ব্যাকআপ আর ফায়ারওয়াল সব চালু করে দেয়। শেষে একটা **Admin token** দেখাবে। **এটা কপি করে নিরাপদ জায়গায় রাখো**, এটা দিয়েই অ্যাডমিন প্যানেলে ঢুকবে (হারালে সার্ভারের `/etc/englio.env` ফাইলে পাবে)।

## ৬. চেক করো

- `https://তোমার-ডোমেইন` ফোনে খোলো, অ্যাপ চলবে।
- `https://তোমার-ডোমেইন/admin.html` খোলো, admin token দিয়ে ঢোকো।
- ফোনে একটা লেসন শেষ করো। "রোজ মনে করিয়ে দেব?" এলে **চালু করো** চাপো আর নোটিফিকেশনের অনুমতি দাও।

**রিমাইন্ডার এখনই টেস্ট করতে:** অ্যাডমিনে Learners-এ নিজেকে খুঁজে **Device id**-টা কপি করো, তারপর সার্ভারে:

```bash
cd /opt/englio && set -a && . /etc/englio.env && set +a && node server/sendReminders.ts --test <device id>
```

কয়েক সেকেন্ডে ফোনে নোটিফিকেশন আসবে। আসল রিমাইন্ডার প্রতি ঘণ্টায় নিজে থেকে যায়: যার যে সময় বাছা, আর যে আজ এখনো শেখেনি, শুধু তাকে।

## ৭. নতুন ভার্সন অনলাইনে দেওয়া

**সহজ উপায় (এটাই ব্যবহার করো):** `CHANGELOG.md`-এ "## Unreleased"-এর নিচে এক-দুই লাইনে লেখো কী বদলালে, সব commit করো, `main` branch-এ থেকে চালাও:

```bash
npm run release -- patch     # ছোট ঠিক করা (1.0.0 → 1.0.1)
npm run release -- minor     # নতুন ফিচার (1.0.0 → 1.1.0)
npm run release -- major     # বড় বদল (1.0.0 → 2.0.0)
```

এটা নিজে নিজে সব টেস্ট চালায় (কিছু ভাঙলে থেমে যায়), ভার্সন বাড়ায়, GitHub-এ push করে, সার্ভারে আপডেট দেয় (সার্ভারের পাসওয়ার্ড চাইবে) আর সাইট ঠিক আছে কি না দেখে। আগে শুধু চেক করতে চাইলে `npm run release -- patch --dry-run`।

**হাতে করতে চাইলে:** GitHub-এ `main`-এ push করো, তারপর সার্ভারে:

```bash
sudo bash /opt/englio/deploy/update.sh
```

শিক্ষার্থীদের ডেটা যেমন আছে তেমনই থাকে। পরের বার অ্যাপ খুললেই সবাই নতুন ভার্সন পায়। Play Store-এর APK আবার বানাতে হয় না।

## ৮. কিছু কাজের কমান্ড

| কী দেখতে চাও | কমান্ড |
| --- | --- |
| API চলছে কি না | `systemctl status englio-api` |
| API-র লগ (লাইভ) | `journalctl -u englio-api -f` (বের হতে Ctrl+C) |
| রিমাইন্ডার কতজনকে গেল | `journalctl -t englio-reminders -n 20` |
| ব্যাকআপ হলো কি না | `ls -lh /var/backups/englio` |
| API রিস্টার্ট | `sudo systemctl restart englio-api` |

## ৯. ব্যাকআপ

প্রতি রাত ৩:৩০-এ ডেটাবেস আর আপলোড করা ছবি ও রেকর্ডিং `/var/backups/englio`-তে কপি হয় (১৪ দিন রাখা হয়)। কিন্তু সার্ভারটাই নষ্ট হলে এগুলোও যাবে, তাই DigitalOcean-এর **Backups** চালু রাখো, অথবা মাঝে মাঝে কম্পিউটারে নামিয়ে রাখো:

```powershell
scp -r root@159.89.10.20:/var/backups/englio ./englio-backup
```

## ১০. পরে আসল ডোমেইনে সরানো

1. নতুন ডোমেইনের DNS-এ একই সার্ভারের IP দাও (২ নম্বর ধাপ)।
2. সার্ভারে একই সেটআপ নতুন ডোমেইন দিয়ে আবার চালাও: `sudo bash deploy/setup.sh নতুন-ডোমেইন.com তোমার@ইমেইল.com`। ডেটাবেস, admin token সব যেমন আছে থাকবে।
3. **APK নতুন ডোমেইন দিয়ে আবার build করতে হবে** (একই package id আর একই signing key দিয়ে)।

**সাবধান:** প্রতিটা ফোনে শিক্ষার্থীর অগ্রগতি সেই ডোমেইনের সাথে বাঁধা থাকে। ডোমেইন বদলালে টেস্টারদের অগ্রগতি নতুন ডোমেইনে নিজে থেকে আসবে না। তারা **ব্যাকআপ কোড** বা ফোন নম্বর দিয়ে ফিরিয়ে আনতে পারবে। তাই **Play Store-এ আসল লঞ্চ আসল ডোমেইন দিয়েই করো**, ডেমো ডোমেইন শুধু টেস্টের জন্য।

## সমস্যা হলে

- **সাইট খুলছে না / HTTPS error:** DNS এখনো ছড়ায়নি, অথবা Cloudflare-এর কমলা মেঘ চালু। `journalctl -u caddy -n 50` দেখো।
- **"502 Bad Gateway":** API বন্ধ। `journalctl -u englio-api -n 50` দেখো।
- **নোটিফিকেশন আসছে না:** ফোনের Settings → Apps → Chrome বা Englio → Notifications চালু আছে কি না দেখো। তারপর ৬ নম্বরের `--test` চালাও।
